# Currency Converter

A React app that converts between currencies from around the world using live exchange rates from [CurrencyAPI](https://currencyapi.com/).

## 🛠️ Tech Stack
- React, Vite
- CurrencyAPI for live exchange rates

## 📦 Setup Instructions

1. Get a free API key from [CurrencyAPI](https://currencyapi.com/)
2. Install dependencies:
   ```bash
   npm install
   ```
3. Copy `.env.example` to `.env` and add your key:
   ```
   VITE_CURRENCY_API_KEY=your_currencyapi_com_key_here
   ```
4. Run the app:
   ```bash
   npm run dev
   ```

## 🌟 Features
- Convert between any two supported currencies
- Swap currencies with one click
- Live exchange rates
